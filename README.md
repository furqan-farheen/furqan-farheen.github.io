# Furqan & Farheen — Wedding Invitation

An animated, illustrated wedding invitation: tap the ribbon to open the envelope, then scroll through
hand-painted Mughal garden scenes with liquid-paint motion, falling petals and gold line-work.

Works on iPhone, iPad, Android and desktop browsers. A printable PDF version is included
(`Furqan-Farheen-Invitation.pdf`).

Built with plain HTML/CSS, a small WebGL shader and GSAP. Fonts: Cormorant Garamond, Cinzel and
Noto Nastaliq Urdu (SIL Open Font License).
